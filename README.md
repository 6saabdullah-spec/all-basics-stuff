# الادوات الي استخدمها

## Visual Studio Code
[تحميل البرنامج](https://code.visualstudio.com/)

البرنامج الي استخدم فيه للغه Java و HTML و CSS.

### نبذة
محرر أكواد خفيف وسريع يعتبر البيئة الرئيسية لكتابة البرامج، ويتميز بتوفير إضافات وتكامل ممتاز يسهل التطوير والتنفيذ.

### الاضافات الي استخدمها
- **Java Extension Pack**
- **Code Runner**
- **Live Server**

---

## DB Browser
[تحميل البرنامج](https://sqlitebrowser.org/dl/)

البرنامج الي استخدم فيه للغه SQL.

### نبذة
أداة رسومية مفتوحة المصدر لإدارة وقواعد البيانات، تُستخدم لإنشاء وتعديل واستعلام قواعد البيانات بلغة SQL بطريقة سهلة ومباشرة دون الحاجة لكتابة أوامر المعالجة المعقدة.
