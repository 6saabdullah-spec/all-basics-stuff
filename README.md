## Visual Studio Code

<p align="center">
  <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/vscode/vscode-original.svg" width="120" alt="VS Code Logo">
</p>

[ تحميل البرنامج](https://code.visualstudio.com/)

البرنامج الرئيسي الذي أستخدمه لكتابة وتطوير أكواد لغات **Java** و **HTML** و **CSS**.

###  نبذة
محرر أكواد خفيف وسريع يعتبر البيئة الرئيسية لكتابة البرامج، ويتميز بتوفير إضافات وتكامل ممتاز يسهل التطوير والتنفيذ.

<p align="center">
  <img src="https://code.visualstudio.com/assets/docs/getstarted/userinterface/hero.png" width="800" alt="VS Code Interface">
</p>

### 🧩 الإضافات الي أستخدمها
- **Java Extension Pack**
- **Code Runner**
- **Live Server**
